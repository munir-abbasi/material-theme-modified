## Description
A custom theme for Open Journal Systems with enhanced user experience featuring improved color schemes, better accessibility, and modern design elements.

## Key Features
- **Enhanced Color Schemes**: Predominant blue color for light theme with excellent contrast ratios
- **Improved Dark Mode**: Much better contrast than previous versions for enhanced readability
- **Accessibility Focused**: WCAG AA compliant contrast ratios and improved focus states
- **Responsive Design**: Optimized for all device sizes
- **Modern UI Elements**: Enhanced buttons, forms, and typography

## Installation
This theme can be installed through the **Plugin Gallery** in Open Journal Systems. If it's not available in the plugin gallery, you may need to update Open Journal Systems to a compatible version.

## Configuration
After installation, the theme can be configured through the Journal Settings interface. The default color scheme is set to blue for optimal user experience, but can be customized to green, indigo, sky, or orange.
