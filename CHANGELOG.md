# Changelog

All notable changes to the Material Theme for Open Journal Systems will be documented in this file.

## [Unreleased]

## [3.5.0.0] - 2026-01-15

### Added
- Enhanced color schemes with predominant blue for light theme
- Improved dark mode with significantly better contrast
- Accessibility improvements with WCAG AA compliant contrast ratios
- Modern UI elements including enhanced buttons and forms
- Custom scrollbar styling for better visibility
- CSS variables for consistent color system

### Changed
- Updated default color option to blue for optimal user experience
- Improved focus states for better keyboard navigation
- Enhanced typography with better contrast in both themes
- Upgraded CSS with Tailwind utilities for improved styling
- Updated template files to use new styling classes
- Improved card designs with better borders and shadows
- Enhanced link styling for better visibility

### Fixed
- Contrast issues in dark mode for better readability
- Accessibility issues with focus indicators
- Form element styling for better usability
- Responsive design elements for all screen sizes

### Security
- Updated dependencies to latest secure versions

## [3.0.5.0] - Previous Release

### Added
- Original Material Theme implementation
- Basic color scheme options (green, indigo, blue, sky, orange)
- Light and dark mode support
- Responsive design elements
